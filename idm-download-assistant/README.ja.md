# IDM ダウンロードアシスタント ヘルプ

## 機能

IDM ダウンロードアシスタントは、Webページから添付リンクを検出し、中国語ファイル名の文字化けを修復し、選択したリンクを IDM ブラウザー拡張機能で一括ダウンロードできるように準備します。

公告、入札、承認、公示、資料ダウンロードなど、PDF、Word、Excel、PPT、DWG、圧縮ファイルなどの添付を含むページで使用できます。

主な機能：

- 現在のページの添付をスキャンします。
- 現在のページから複数の親リストページを連続してスキャンします。
- 第1階層、第2階層、第3階層のページ探索に対応します。
- 各親ページから開く第2階層ページ数と、各第2階層ページから開く第3階層ページ数を制限できます。
- 一部の中国語文字化け、URLエンコード名、サーバー生成ファイル名を修復します。
- ファイル名を直接編集できます。
- 取り消し可能な接頭辞と接尾辞を使用できます。
- IDM 拡張機能で一括ダウンロードできるようにリンクを準備します。
- TXT、CSV、Excel に書き出せます。
- 最小化状態を別ページでも保持します。

## 使用方法

添付を含むページを開くと、右側に `IDM ダウンロードアシスタント` パネルが表示されます。

1行目で探索範囲を設定します。

- `1 件のリストページを取得`：現在のリストページから何件の親リストページをスキャンするかを指定します。
- `探索階層`：`第1階層` はリストページのみ、`第2階層` は詳細ページまで、`第3階層` はさらに次の階層まで入ります。
- `各階層最大 N 件の子ページ`：各親リストページから開く第2階層ページ数、各第2階層ページから開く第3階層ページ数の上限です。

2行目で主要操作を実行します。

- `探索を開始`：現在の設定で添付をスキャンします。
- `選択項目をコピー → IDM`：選択したリンクと修復済みファイル名をコピーします。
- `IDM拡張機能を準備`：IDM ブラウザー拡張機能が使用できるリンク領域を作成します。
- `作者を支援`：作者支援ページを開きます。
- `ヘルプ`：現在の言語のヘルプページを開きます。

3行目で結果を選択、絞り込みできます。

- `すべて選択`
- `すべて解除`
- `選択を反転`
- 検索ボックス
- `絞り込み結果を選択`

結果リストのファイル名は直接編集できます。黄色のファイル名欄は、サーバー生成名、ハッシュ名、文字化けなど、名前が信頼できない可能性を示します。

接頭辞と接尾辞は既定では無効です。`接頭辞` または `接尾辞` をチェックすると入力内容が適用され、チェックを外すとこの機能で追加した内容が削除されます。接尾辞は拡張子の前に挿入されます。例：`filename_published.pdf`。

IDM に渡す推奨手順：

1. ダウンロードしたい添付を選択します。
2. `IDM拡張機能を準備` をクリックします。
3. 表示された青いリンク領域内で右クリックします。
4. IDM 拡張機能の `IDMで選択したリンクをダウンロード` または類似コマンドを選びます。
5. IDM の一括ダウンロード画面でファイル、保存先、フィルターを確認します。

`TXTを書き出し`、`CSVを書き出し`、`Excelを書き出し` で現在の結果を書き出せます。

タイトルバーの `−` をクリックすると小さなアイコンに最小化されます。アイコンをクリックすると復元します。`×` をクリックすると現在のページ上のパネルを非表示にします。

## FAQ

### 直接すべてのリンクを静かにダウンロードできないのはなぜですか？

通常のWebページスクリプトは、IDM クライアントの内部ダウンロードAPIを直接呼び出せません。スクリプトは IDM 拡張機能が認識できる形式でリンクを準備し、IDM の標準一括ダウンロード画面を開かせます。

### 一部のファイル名が文字化けするのはなぜですか？

一部のサイトは古いエンコード、誤ったエンコード、URLエンコード、サーバー応答ヘッダーでファイル名を渡します。スクリプトは修復を試みますが、すべてのサイトで完全に復元できるとは限りません。黄色のファイル名欄は手動で編集できます。

### リストページ数とは何ですか？

現在のリストページから後続ページをたどって何件の親リストページをスキャンするかを表します。例えば `26` は現在のページから26件の親ページをスキャンしようとします。

### 各階層最大とは何ですか？

親リストページ数ではなく、子ページ数の制限です。各親ページから開く第2階層ページ数、各第2階層ページから開く第3階層ページ数を制限します。

### ヘルプが言語ごとに変わるのはなぜですか？

スクリプトはブラウザー言語に基づいてヘルプファイルを選択します。現在は簡体字中国語、繁体字中国語、英語、日本語、ドイツ語、ロシア語に対応しています。未対応の言語では英語ヘルプを開きます。

## プライバシー

スクリプトはブラウザー内でローカルに動作し、ページ内容、添付リンク、ファイル名を能動的にアップロードしません。

添付検出とファイル名識別のために、現在のページを読み取り、同一サイトのリストページ、詳細ページ、添付URLを要求する場合があります。

外部ページは、`ヘルプ` または `作者を支援` をクリックした場合にのみ開きます。
