# IDM 下载助手帮助

## 功能介绍

IDM 下载助手用于从网页中嗅探附件链接，修复常见中文文件名乱码，并把选中的链接交给 IDM 浏览器插件进行批量下载。

适用页面包括公告、公示、招投标、项目审批、资料下载等包含 PDF、Word、Excel、PPT、DWG、压缩包附件的网页。

主要功能：

- 扫描当前网页附件。
- 从当前页开始连续抓取多个列表父页面。
- 支持一级、二级、三级网页嗅探。
- 可限制每个父页面下的二级页面数量，以及每个二级页面下的三级页面数量。
- 修复部分中文乱码、URL 编码和服务器机器名文件名。
- 文件名可直接手动编辑。
- 支持可撤销的前缀和后缀。
- 支持交给 IDM 插件批量下载。
- 支持导出 TXT、CSV、Excel。
- 最小化状态可在不同网页间记住。

## 使用说明

打开需要提取附件的网页后，右侧会出现 `IDM下载助手` 面板。

第一行用于设置嗅探范围：

- `抓取 1 个列表页`：从当前列表页开始，向后连续抓取多少个列表父页面。
- `嗅探级别`：`一级` 只扫描列表页；`二级` 会进入详情页；`三级` 会继续进入下一层页面。
- `每级最多 N 个子页面`：每个列表父页面最多进入多少个二级页面；每个二级页面最多进入多少个三级页面。

第二行用于执行主要操作：

- `开始嗅探`：按当前设置扫描附件。
- `复制选中→IDM`：复制选中的链接和修复后的文件名。
- `准备IDM插件`：生成可供 IDM 浏览器插件识别的链接区域。
- `支持作者`：打开作者支持页面。
- `帮助`：打开当前语言的帮助页。

第三行用于选择和筛选结果：

- `全选`
- `全不选`
- `反选`
- 搜索框
- `勾选筛选结果`

结果列表中的文件名可以直接修改。黄色文件名框表示该名称可能不可靠，例如服务器生成名、哈希名或乱码名。

前缀和后缀默认不启用。勾选 `前缀` 或 `后缀` 后会应用输入框内容；取消勾选会撤销由该功能添加的内容。后缀会插入到扩展名前，例如 `文件名_已发布.pdf`。

推荐使用 `准备IDM插件` 交给 IDM 下载：

1. 勾选需要下载的附件。
2. 点击 `准备IDM插件`。
3. 在弹出的蓝色链接区域内右键。
4. 选择 IDM 插件中的 `使用 IDM 下载选定链接` 或类似命令。
5. 在 IDM 原生批量下载窗口中确认文件、保存目录和筛选项。

可以使用 `导出TXT`、`导出CSV`、`导出Excel` 导出当前结果。

点击标题栏的 `−` 可以最小化为小图标；点击小图标可以恢复。点击 `×` 会隐藏当前页面上的面板。

## FAQ

### 为什么不能直接静默下载全部链接？

普通网页脚本不能直接调用 IDM 客户端的内部下载接口。脚本只能把链接准备成 IDM 插件可识别的形式，再由 IDM 插件打开原生批量下载窗口。

### 为什么有些文件名是乱码？

部分网站使用旧编码、错误编码、URL 编码或服务器响应头传递文件名。脚本会尝试修复，但不能保证所有网站都能完全恢复。黄色文件名框可以手动修改。

### 抓取多少页是什么意思？

它表示从当前列表页开始，沿着后续分页继续抓取多少个列表父页面。例如填写 `26`，就是从当前页开始尝试抓取 26 个父页面。

### 每级最多多少页是什么意思？

它限制下级页面数量，不是列表父页面数量。它表示每个列表父页面下最多进入多少个二级页面，以及每个二级页面下最多进入多少个三级页面。

### 为什么点击帮助会显示不同语言？

脚本会根据浏览器语言选择帮助文件。当前支持简体中文、繁体中文、英文、日文、德文、俄文。不支持的语言会打开英文帮助。

## 隐私

脚本在浏览器本地运行，不会主动上传网页内容、附件链接或文件名。

脚本会读取当前页面内容，并可能请求同站点的列表页、详情页和附件地址，用于嗅探附件和识别文件名。

只有在点击 `帮助` 或 `支持作者` 时，脚本才会打开对应的外部页面。
