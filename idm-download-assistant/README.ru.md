# Помощник загрузки IDM: справка

## Возможности

Помощник загрузки IDM ищет ссылки на вложения на веб-страницах, исправляет распространённые ошибки кодировки китайских имён файлов и подготавливает выбранные ссылки для пакетной загрузки через браузерное расширение IDM.

Подходит для страниц объявлений, закупок, согласований, публичных уведомлений и загрузки материалов с вложениями PDF, Word, Excel, PPT, DWG, архивами и похожими файлами.

Основные возможности:

- Сканирование вложений на текущей странице.
- Сканирование нескольких родительских страниц списка, начиная с текущей.
- Поиск страниц уровня 1, 2 и 3.
- Ограничение количества страниц уровня 2 для каждой родительской страницы и страниц уровня 3 для каждой страницы уровня 2.
- Исправление части китайской mojibake, URL-кодированных и серверных имён файлов.
- Ручное редактирование имён файлов.
- Отменяемые префиксы и суффиксы.
- Подготовка ссылок для пакетной загрузки IDM.
- Экспорт TXT, CSV и Excel.
- Запоминание свёрнутого состояния между страницами.

## Использование

Откройте страницу с вложениями. Справа появится панель `Помощник загрузки IDM`.

Первая строка задаёт область поиска:

- `Сканировать 1 страницу списка`: сколько родительских страниц списка сканировать, начиная с текущей страницы.
- `Глубина поиска`: `Уровень 1` сканирует только страницы списка; `Уровень 2` открывает страницы деталей; `Уровень 3` открывает ещё один уровень ссылок.
- `Максимум N дочерних страниц на уровень`: максимальное количество страниц уровня 2 для каждой родительской страницы и страниц уровня 3 для каждой страницы уровня 2.

Вторая строка выполняет основные действия:

- `Начать поиск`: сканировать вложения с текущими настройками.
- `Копировать выбранное → IDM`: скопировать выбранные ссылки и исправленные имена файлов.
- `Подготовить расширение IDM`: создать область ссылок, которую может использовать расширение IDM.
- `Поддержать автора`: открыть страницу поддержки автора.
- `Справка`: открыть справку на текущем языке.

Третья строка выбирает и фильтрует результаты:

- `Выбрать все`
- `Снять выбор`
- `Инвертировать`
- поле поиска
- `Выбрать отфильтрованное`

Имена файлов в списке результатов можно редактировать напрямую. Жёлтое поле имени означает, что имя может быть ненадёжным: серверное имя, хеш-имя или ошибка кодировки.

Префикс и суффикс по умолчанию отключены. Установите флажок `Префикс` или `Суффикс`, чтобы применить введённый текст; снимите флажок, чтобы удалить текст, добавленный этой функцией. Суффикс вставляется перед расширением, например `filename_published.pdf`.

Рекомендуемый порядок работы с IDM:

1. Выберите вложения, которые нужно скачать.
2. Нажмите `Подготовить расширение IDM`.
3. Щёлкните правой кнопкой мыши в синей области ссылок.
4. В расширении IDM выберите `Скачать выбранные ссылки с помощью IDM` или похожую команду.
5. Подтвердите файлы, папку сохранения и фильтры в родном окне пакетной загрузки IDM.

Используйте `Экспорт TXT`, `Экспорт CSV` или `Экспорт Excel`, чтобы экспортировать текущие результаты.

Нажмите `−` в заголовке, чтобы свернуть панель в маленький значок. Нажмите значок, чтобы восстановить панель. Нажмите `×`, чтобы скрыть панель на текущей странице.

## FAQ

### Почему нельзя напрямую и бесшумно скачать все ссылки?

Обычный веб-скрипт не может напрямую вызвать внутренний API загрузки клиента IDM. Скрипт может только подготовить ссылки в форме, которую распознаёт расширение IDM, а затем IDM открывает родное окно пакетной загрузки.

### Почему некоторые имена файлов отображаются с ошибкой кодировки?

Некоторые сайты передают имена файлов через старые кодировки, неправильные кодировки, URL-кодирование или серверные заголовки. Скрипт пытается исправить их, но не каждый сайт можно полностью восстановить. Жёлтые поля имён можно редактировать вручную.

### Что означает количество страниц списка?

Это количество родительских страниц списка, которые нужно просканировать от текущей страницы через последующую пагинацию. Например, `26` означает попытку просканировать 26 родительских страниц, начиная с текущей.

### Что означает максимум на уровень?

Это ограничение дочерних страниц, а не родительских страниц списка. Оно задаёт, сколько страниц уровня 2 можно открыть для каждой родительской страницы и сколько страниц уровня 3 можно открыть для каждой страницы уровня 2.

### Почему справка открывается на разных языках?

Скрипт выбирает файл справки по языку браузера. Сейчас поддерживаются упрощённый китайский, традиционный китайский, английский, японский, немецкий и русский. Для неподдерживаемых языков открывается английская справка.

## Конфиденциальность

Скрипт работает локально в браузере и не отправляет содержимое страниц, ссылки на вложения или имена файлов по своей инициативе.

Для поиска вложений и определения имён файлов скрипт читает текущую страницу и может запрашивать страницы списка, страницы деталей и URL вложений на том же сайте.

Внешние страницы открываются только при нажатии `Справка` или `Поддержать автора`.
