# IDM 下載助手幫助

## 功能介紹

IDM 下載助手用於從網頁中嗅探附件連結、修復常見中文檔名亂碼，並把選取的連結交給 IDM 瀏覽器外掛進行批次下載。

適用頁面包括公告、公示、招投標、專案審批、資料下載等包含 PDF、Word、Excel、PPT、DWG、壓縮包附件的網頁。

主要功能：

- 掃描目前網頁附件。
- 從目前頁開始連續抓取多個列表父頁面。
- 支援一級、二級、三級網頁嗅探。
- 可限制每個父頁面下的二級頁面數量，以及每個二級頁面下的三級頁面數量。
- 修復部分中文亂碼、URL 編碼和伺服器機器名稱檔名。
- 檔名可直接手動編輯。
- 支援可撤銷的前綴和後綴。
- 支援交給 IDM 外掛批次下載。
- 支援匯出 TXT、CSV、Excel。
- 最小化狀態可在不同網頁間記住。

## 使用說明

開啟需要擷取附件的網頁後，右側會出現 `IDM下載助手` 面板。

第一行用於設定嗅探範圍：

- `抓取 1 個列表頁`：從目前列表頁開始，向後連續抓取多少個列表父頁面。
- `嗅探層級`：`一級` 只掃描列表頁；`二級` 會進入詳情頁；`三級` 會繼續進入下一層頁面。
- `每級最多 N 個子頁面`：每個列表父頁面最多進入多少個二級頁面；每個二級頁面最多進入多少個三級頁面。

第二行用於執行主要操作：

- `開始嗅探`：依目前設定掃描附件。
- `複製所選→IDM`：複製所選連結和修復後的檔名。
- `準備IDM外掛`：生成可供 IDM 瀏覽器外掛識別的連結區域。
- `支持作者`：開啟作者支持頁面。
- `幫助`：開啟目前語言的幫助頁。

第三行用於選擇和篩選結果：

- `全選`
- `全部取消`
- `反向選取`
- 搜尋框
- `勾選篩選結果`

結果列表中的檔名可以直接修改。黃色檔名欄表示該名稱可能不可靠，例如伺服器產生名稱、雜湊名稱或亂碼名稱。

前綴和後綴預設不啟用。勾選 `前綴` 或 `後綴` 後會套用輸入框內容；取消勾選會撤銷由該功能加入的內容。後綴會插入到副檔名前，例如 `檔名_已發布.pdf`。

建議使用 `準備IDM外掛` 交給 IDM 下載：

1. 勾選需要下載的附件。
2. 點擊 `準備IDM外掛`。
3. 在彈出的藍色連結區域內按右鍵。
4. 選擇 IDM 外掛中的 `使用 IDM 下載選定連結` 或類似命令。
5. 在 IDM 原生批次下載視窗中確認檔案、儲存目錄和篩選項。

可以使用 `匯出TXT`、`匯出CSV`、`匯出Excel` 匯出目前結果。

點擊標題列的 `−` 可以最小化為小圖示；點擊小圖示可以恢復。點擊 `×` 會隱藏目前頁面上的面板。

## FAQ

### 為什麼不能直接靜默下載全部連結？

普通網頁腳本不能直接呼叫 IDM 客戶端的內部下載介面。腳本只能把連結準備成 IDM 外掛可識別的形式，再由 IDM 外掛開啟原生批次下載視窗。

### 為什麼有些檔名是亂碼？

部分網站使用舊編碼、錯誤編碼、URL 編碼或伺服器回應標頭傳遞檔名。腳本會嘗試修復，但不能保證所有網站都能完全恢復。黃色檔名欄可以手動修改。

### 抓取多少頁是什麼意思？

它表示從目前列表頁開始，沿著後續分頁繼續抓取多少個列表父頁面。例如填寫 `26`，就是從目前頁開始嘗試抓取 26 個父頁面。

### 每級最多多少頁是什麼意思？

它限制下級頁面數量，不是列表父頁面數量。它表示每個列表父頁面下最多進入多少個二級頁面，以及每個二級頁面下最多進入多少個三級頁面。

### 為什麼點擊幫助會顯示不同語言？

腳本會根據瀏覽器語言選擇幫助文件。當前支援簡體中文、繁體中文、英文、日文、德文、俄文。不支援的語言會開啟英文幫助。

## 隱私

腳本在瀏覽器本地執行，不會主動上傳網頁內容、附件連結或檔名。

腳本會讀取目前頁面內容，並可能請求同站點的列表頁、詳情頁和附件地址，用於嗅探附件和識別檔名。

只有在點擊 `幫助` 或 `支持作者` 時，腳本才會開啟對應的外部頁面。
